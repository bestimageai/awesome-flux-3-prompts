## Browse by starting asset

- **No source media:** text-to-video recipes, including C01–C06, D01–D06, N01–N06, M01–M04, M06, X01, X03, X06 and F01–F03.
- **One approved first frame:** A01/A04, E02/E03/E05/E06, T01/T03/T06, S06, B01/B02, M05, R01/R04/R06, X02/X04 and F04–F06.
- **Two approved endpoints:** R02/R05, B05, X05 and F07–F09.
- **An authorized clip:** R03 and F10–F12. Preserve the source's ratio, motion and scene state.

Use the per-entry mode as the authority; this shortlist is a navigation aid, not an additional prompt count.

## Counting and maintenance

The collection contains 72 creative scenes across twelve topical packs and 12 API workflow briefs, for a total of 84 prompts.

Each canonical entry has one stable ID and one complete copyable `text` block. Change the index, [use-case matrix](../docs/use-case-matrix.md) and landing-page statistics whenever a complete recipe is added. Do not increase counts for a planned or incomplete item.
